THDC Visitor Management

A Flask-based visitor management system

This repository contains a full visitor management web app — OTP mobile verification, an emailed digital Visitor Pass, and a role-based admin dashboard — built with Python (Flask), HTML, and CSS.

  • 📝 THDC Visitor Form with automatic date & time recording
  • 📲 OTP mobile number verification
  • 🎫 Emailed Visitor Pass with a unique Pass ID
  • 🔐 Role-based admin access (Head Admin + Admins)
  • 📊 Unified dashboard: Visitors, Manage Admins, Login Activity
This is a static landing page for the GitHub repository only. The actual app is a Python Flask server and can't run on GitHub Pages — clone the repo and follow the README to run it locally.
